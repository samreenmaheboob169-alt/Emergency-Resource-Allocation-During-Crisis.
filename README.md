# 🚨 Emergency Resource Allocation During Crisis

## 📌 Project Overview
Emergency Resource Allocation During Crisis is a Java-based desktop application developed using Java Swing. It helps manage emergency requests and allocate essential resources efficiently during disasters, accidents, fires, and other crisis situations.

The application uses a **Priority Queue** to process emergency requests according to their severity, ensuring that critical emergencies are handled before lower-priority requests.

## 🎯 Objectives
- Efficiently manage emergency requests.
- Prioritize emergencies based on severity.
- Allocate resources systematically.
- Monitor pending and allocated emergencies.
- Provide a simple and user-friendly graphical interface.

## ✨ Key Features
- Emergency registration with location details.
- People affected information.
- Resource selection (Ambulance, Fire Truck, Medical Team, Food Supply, Rescue Team).
- Four emergency priority levels: Critical, High, Medium, Low.
- Priority-based resource allocation using Priority Queue.
- Dashboard displaying total, pending, and allocated emergencies.
- Emergency request and allocation tracking tables.

## 🛠️ Technologies Used
- **Programming Language:** Java
- **GUI:** Java Swing
- **Data Structure:** Priority Queue
- **Libraries:** Java AWT, Swing, Java Time API
- **IDE:** Visual Studio Code

## ⚙️ How to Run the Project

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder in VS Code.

3. Compile the Java program:

   ```bash
   javac EmergencyResourceAllocation.java
   ```

4. Run the application:

   ```bash
   java EmergencyResourceAllocation
   ```

## 📊 Working Principle
1. Enter the emergency location and number of people affected.
2. Select the required emergency resource.
3. Choose the emergency priority.
4. Add the emergency request.
5. The system stores the request in a Priority Queue.
6. Allocate resources based on emergency priority.
7. Monitor the allocation status through the dashboard.
